# Week 3 Summary – Monitoring & Threat Detection

## Overview
This week focused on monitoring, visibility, and threat detection in Azure.
The labs simulated how security teams track activity, detect potential threats, and prepare for incident investigation.

## Labs Completed
- Azure Activity Logs – Administrative Event Monitoring
- Microsoft Defender for Cloud – Security Alerts
- Log Analytics Workspace – Centralized Logging

## Key Skills Practiced
- Reviewing administrative and system activity logs
- Understanding the difference between logs and security alerts
- Identifying where security incidents and alerts are surfaced
- Creating centralized logging infrastructure for monitoring
- Applying monitoring concepts used in SOC environments

## What I Learned
- Activity Logs provide an audit trail of actions performed in Azure
- Security alerts highlight potential threats and misconfigurations
- Centralized logging is critical for investigation and detection
- Monitoring and detection are foundational to cloud security operations

## Reflection
This week strengthened my understanding of how visibility and monitoring support cloud security.
I gained hands-on experience reviewing logs, locating security alerts, and deploying centralized logging infrastructure.
These skills are essential for SOC and cloud security roles.
