# Azure Cloud Security Labs

This repository contains my **early hands-on labs in Azure cloud security**.  
It is my **first Azure-focused repository**, created primarily to **learn, explore, and gain practical experience using the Azure Portal**.

The labs here focus on understanding **core cloud security concepts** and becoming comfortable navigating and configuring security-related services in Azure.

---

##  Purpose of This Repository

- Learn how Azure security services work in practice
- Gain familiarity with the Azure Portal interface
- Understand basic cloud security workflows
- Build foundational knowledge before moving into advanced Azure administration and security labs

This repository represents my **starting point in Azure and cloud security**.

---

##  Topics Covered

- Identity and Access Management (IAM)
- Role-Based Access Control (RBAC)
- Multi-Factor Authentication (MFA)
- Cloud Security Posture Management (CSPM)
- Logging and Monitoring
- Basic Incident Investigation and Response

---

##  Tools & Services Used

- **Azure Portal**
- **Microsoft Entra ID (Azure Active Directory)**
- **Microsoft Defender for Cloud**
- **Microsoft Sentinel**
- **Azure Monitor**
- **Log Analytics**
- **KQL (basic queries)**

---

##  Lab Highlights

- Configured basic RBAC roles for Azure identities
- Enabled and tested Multi-Factor Authentication (MFA)
- Reviewed security recommendations in Defender for Cloud
- Explored security alerts and incidents in Microsoft Sentinel
- Practiced basic log queries using KQL
- Observed how security events are monitored and investigated in Azure

---

##  Learning Focus

These labs are **learning-oriented**, not production-grade implementations.  
The emphasis is on:

- Understanding **what each security service does**
- Knowing **where to look in the Azure Portal**
- Learning how alerts, logs, and recommendations are presented
- Building confidence before moving to more advanced Azure security and administration labs
