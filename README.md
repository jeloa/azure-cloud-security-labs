# AZURE CLOUD SECURITY LABS

This repository contains hands-on Azure cloud security labs focused on:
- Identity and Access Management
- Cloud Security Posture Management
- Logging and Monitoring
- Incident Response

## Tools & Technologies
- Azure Portal
- Entra ID (Azure AD)
- Microsoft Defender for Cloud
- Microsoft Sentinel
- Azure Monitor & Log Analytics
- KQL (basic)

## Lab Highlights
- Configured RBAC and MFA for Azure identities
- Assessed cloud security posture using Defender for Cloud
- Investigated security alerts using Microsoft Sentinel
- Responded to simulated cloud security incidents

## Objective
To build practical, job-ready cloud security experience and demonstrate hands-on skills for junior cybersecurity and cloud security roles.
