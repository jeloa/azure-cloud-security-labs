# Week 1 Summary – Identity and Access Management

## Overview
This week focused on securing Azure identities by applying core Identity and Access Management (IAM) principles using Microsoft Entra ID.

The labs simulated real-world identity security tasks commonly performed by cloud and security analysts.

## Labs Completed
- User and RBAC Configuration
- Multi-Factor Authentication (MFA)
- Sign-In Log Analysis

## Key Skills Practiced
- Managing Azure identities and roles
- Enforcing least-privilege access
- Implementing MFA for account protection
- Reviewing authentication logs for security insights

## What I Learned
- How RBAC limits user access and reduces security risk
- Why MFA is critical for preventing credential-based attacks
- How sign-in logs are used to investigate authentication activity
- How identity security supports a Zero Trust model

## Reflection
This week strengthened my understanding of identity as the primary security perimeter in cloud environments and improved my confidence navigating Azure security tools.
