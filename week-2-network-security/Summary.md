# Week 2 Summary – Network Security and Governance

## Overview
This week focused on securing Azure resources at the network and governance level.  
The labs simulated real-world cloud security controls used to reduce exposure, prevent misconfigurations, and protect critical resources.

## Labs Completed
- Network Security Groups (NSG) – Traffic Control
- Microsoft Defender for Cloud – Security Posture Review
- Azure Resource Locks – Prevent Accidental Deletion

## Key Skills Practiced
- Controlling inbound network traffic using NSGs
- Applying default-deny security principles
- Reducing attack surface by limiting exposed ports
- Protecting resources using Azure governance controls
- Understanding cloud security posture concepts

## What I Learned
- How NSGs act as a firewall at the subnet and resource level
- Why default-deny rules are critical in cloud environments
- How human error is a major security risk and how resource locks help prevent it
- How cloud platforms assess security posture using recommendations and secure scores

## Reflection
This week strengthened my understanding of how cloud environments are secured beyond identity controls.
I gained hands-on experience applying network security rules, governance protections, and reviewing cloud security posture using Defender for Cloud.
These labs improved my ability to think in terms of risk reduction and preventative security controls.
