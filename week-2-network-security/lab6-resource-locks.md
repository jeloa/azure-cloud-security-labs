# Azure Resource Locks – Prevent Accidental Deletion

## Objective
To protect critical Azure resources by applying resource locks and preventing accidental deletion.

## Tools Used
- Azure Portal
- Azure Resource Manager

## Steps Performed
1. Selected an existing resource group
2. Applied a delete lock to prevent removal
3. Verified lock enforcement

## Security Analysis
- Resource locks reduce the risk of accidental or unauthorized changes
- Supports operational security and change management practices

## Outcome
- Successfully protected resources from accidental deletion
- Improved understanding of Azure governance controls

## Security Concepts Learned
- Resource governance
- Change control
- Operational security
